
## Привет! Я Влада

Выпускница бакалавриата по специальности "Программирование и дизайн виртуальной и дополненной реальности". Более 4 лет занимаюсь разработкой проектов на Unity и имею опыт работы с Unreal Engine.

## Технологии

- Unity
- C#
- VR / AR
- Unreal Engine
- Git
